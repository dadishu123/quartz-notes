## 问题现象

GitHub Actions显示成功，
仓库内容正确，
但网页仍显示上一版本。

## 排查过程

1. 检查 content
2. 检查 git commit
3. 检查 GitHub Actions
4. 检查 Pages deployment

均正常。

## 原因

浏览器缓存。

Quartz启用SPA模式，
新增/删除页面涉及：

- Explorer
- Graph
- contentIndex

等静态资源。

浏览器可能继续使用旧缓存。

## 解决

Ctrl + F5 强制刷新。

或者：

URL增加版本参数：

?v=timestamp

## 结论

发布流程正常。
